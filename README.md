# Spotify Tracks Analysis (Milestone 1 - CIE)

## Overview
This repository contains the dataset and complete Python implementation for the Applied Python for Data Analytics assignment (Milestone 1). The project handles data cleaning, data transformation, null value imputation using mean metrics, insight generation, and visualization using a Spotify tracks dataset.

## Repository Details
- **USN & Section Format:** `USN_SECTION` (e.g., Your_USN_Your_Section)
- **Dataset:** `spotify_tracks_data.csv`
- **Script/Notebook:** `spotify_analysis.py`

## Methodology
1. **Data Understanding:** Explored column types, record count, and statistical shape.
2. **Data Transformation:** Standardized Milliseconds to Minutes (`Duration_Mins`) and cleaned unnecessary metrics.
3. **Null Handling:** Handled missing elements in continuous columns (`Streams`, `Popularity`) using **Mean Imputation**.
4. **Insight Generation & Visualization:** Evaluated top-streamed genres and yearly average track popularities.
